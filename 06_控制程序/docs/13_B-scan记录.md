# 13 B-scan 测试记录（07 第 2 周：测试信号版）

## 一句话
10/6 晚–10/7 凌晨：找到并量了 P0.6，定了触发链路（P0.6 → 发生器外触发 → TRIG IN + 测试脉冲 → CH A），`bscan_test.m` 第一次真正采到 B-scan：滑台 4 mm/s 移动、400 条、每条都有测试脉冲且位置一致（标准差 1.84 ns）。给导师的图：`docs/figures/bscan_test_20261007.png`。

## 1 接线（10/7 测试用，激光不接）
```
NI P0.6 ─ 蓝线 ─ BNC-2110 端子 USER 1 ─ 面板 USER 1 BNC ─ 三通（示波器 CH1）─ 三通（发生器背面 CH1 AUX IN/OUT）─ 发生器背面 CH2 AUX IN/OUT
发生器 G1（CH1 输出）─ 三通（示波器 CH2）─ ATS9462 TRIG IN
发生器 G2（CH2 输出）─ 三通（示波器 CH3）─ ATS9462 CH A
```
- P0.6 原来的蓝线另一头是空的（10/6 晚确认），现在插在 BNC-2110 上排 USER 1 端子（D GND 右边一个，`HW_BNC2110_P06_in_USER1.jpg`）。
- DG852 Pro 每个通道只认自己背面的 AUX IN/OUT 口，所以 P0.6 要同时接两个 AUX 口。

## 2 发生器设置（DG852 Pro，`HW_DG852_burst_settings_1007.jpg`）
| | CH1（→ TRIG IN） | CH2（→ CH A，测试脉冲） |
|---|---|---|
| 波形 | Square 100 kHz，2 Vpp，Offset 1 V，Duty 50% → 0→2 V、5 µs | Square 2.5 MHz，1 Vpp，Offset 0.5 V，Duty 50% → 0→1 V、200 ns |
| Burst | NCycle，Cycles 1，Source **Ext Leading**，Delay 0，Idle **Bottom**，Phase 0° | 同左，**Delay 2 µs** |
| Channel 页 | Imped **Load**（50 Ω），Sync Off，Trig Out Off | 同左 |

注意：AUX IN/OUT 是双向口。先把 Source 设成 Ext、Sync/Trig Out 关掉，再接 P0.6，否则两个输出会顶在一起。

**怎么理解**
- 上升沿比发生器设的 2 µs 早约 62 ns：和 docs/10 里"ATS 比示波器早约 70 ns"一致，来源待确认。
- 标准差 1.84 ns ≈ 5.56 ns / √12 = 1.6 ns：ATS 采样时钟和触发不同步，触发落在一个采样间隔内的位置是均匀随机的。图 (c) 里能看到斜条纹，每约 5.6 ns 折回一次：触发周期（1.25 ms，NI 时钟）和 180 MHz 采样时钟之间的相位在一条条地匀速走动。所以散布来自采样本身，不是系统抖动。
- 位置用的是命令位置（commanded），不是实测位置。
