10/10 补充（**已更正，见 §3.3**）：§3.2 里"TRIG IN 是高阻、改用 1.5 Vpp / 0.75 V"是误读——示波器 CH2 的 Probe 被设成了 2X，所有 CH2 读数都翻了倍。实测 TRIG IN 是 **50 Ω**（万用表 50.2 Ω；TRIG IN 端示波器 Top 1.96 V）。**G1 仍用上表的 2 Vpp / 1 V**（TRIG IN 上 0→2 V，峰值约 2.7 V）。不要用 1 Vpp / 0.5 V：TRIG IN 上只有 1.0 V，只比门槛 0.87 V（code 150）高 0.13 V，§3.2 里三次都漏触发。改 Ampl 时 Offset 要一起改（Offset = Ampl/2，低电平才是 0 V）。示波器每次开始前先看各通道 Probe 是不是 1X。

注意：AUX IN/OUT 是双向口。先把 Source 设成 Ext、Sync/Trig Out 关掉，再接 P0.6，否则两个输出会顶在一起。

**10/14 补充（台架被人动过后的三处坑，详见 docs/14 末尾 10/14 记录）：**
- 发生器背面从上到下是 **10MHz REF IN/OUT → CH1 AUX → CH2 AUX**。三通要插在 **CH1 AUX** 上，短线接 **CH2 AUX**，**10MHz REF 必须空着**。10/14 三通插在了 REF 上：发生器的 10 MHz 参考时钟被送进 USER 1/P0.6 这条线（示波器 CH1 显示 10.0 MHz、Vpp 约 2.5 V），ctr1 多数（打 5 发数到 89，P0.6 保持 0 时 2 s 数到 121），G2 也不触发。
- CH2 的波形必须是 **Square**。10/14 被改成了 Sine：一个周期的正弦没有陡边沿，还从中间电平开始，B-scan 快速检查里的上升沿和 nEdge 都会不准。
- 示波器先按一下 HORIZONTAL 区上面那个旋钮（POSITION），把 **D 归零**。10/14 D 是 39 ms，屏幕看的是触发后 39 ms，脉冲全都看不到。

**怎么理解**
- 上升沿比发生器设的 2 µs 早约 62 ns：和 docs/10 里"ATS 比示波器早约 70 ns"一致，来源待确认。
- 标准差 1.84 ns ≈ 5.56 ns / √12 = 1.6 ns：ATS 采样时钟和触发不同步，触发落在一个采样间隔内的位置是均匀随机的。图 (c) 里能看到斜条纹，每约 5.6 ns 折回一次：触发周期（1.25 ms，NI 时钟）和 180 MHz 采样时钟之间的相位在一条条地匀速走动。所以散布来自采样本身，不是系统抖动。
- 位置用的是命令位置（commanded），不是实测位置。

### 7.2 时间轴：每个时刻从哪个设置来
以 CH1 上升沿为 0：
```
t = 0        CH1  P0.6 上升（触发点）
t ≈ 0.55 µs  CH2  G1 上升     ← 发生器外触发的反应时间（Dly↑1→2 = 550 ns）
t ≈ 2.56 µs  CH3  G2 上升     ← G1 + Burst Delay 2 µs
t ≈ 2.76 µs  CH3  G2 下降     ← + 200 ns = 2.5 MHz 的半个周期（Burst 1 个周期、Duty 50%）
t ≈ 5.56 µs  CH2  G1 下降     ← G1 + 5 µs = 100 kHz 的半个周期
t ≈ 8.06 µs  CH1  P0.6 下降   ← 2 行 × 1/248 kS/s（屏幕外，所以 CH1 的 Fall 是 *****）
```
- **tVmax / tVmin** = 最高点、最低点出现在触发后多久。最高点是上升沿刚过的过冲尖，最低点是下降沿刚过的下冲尖，所以可以用来定位边沿。
- **+Wid** = 在 50 % 高度量的正脉宽：CH2 5.000 µs、CH3 200.0 ns，和发生器频率对得上。
- **G1 → G2** = 2.560 − 0.560 = 2.00 µs = 发生器 Delay（10/9 用更细时基量到 1.980 µs）。
- **ATS 量到的上升沿 1.926–1.933 µs** 比 2.0 µs 早约 50–70 ns：ATS 从 G1 越过 0.87 V 开始计时，这是一个固定偏差，以前一直有（§3、§3.3），来源待确认。
- P0.6 → G1 的延迟不进数据：ATS 从 G1 开始计时，而且 4 mm/s 下 550 ns 只走 2 nm。

### 7.3 电压：为什么 CH2 是 2 V、CH3 是 1 V
发生器设 **Imped = Load**：它假定另一头是 50 Ω，按这个输出。另一头**真有 50 Ω** → 量到的就是设定值；另一头**开路**（只有 1 MΩ 示波器）→ **翻倍**。所以这两个读数本身就是阻抗检查：

| 通道 | Top | 说明 | 不对时 |
|---|---|---|---|
| CH1 P0.6 | 4.48 V | P0.6 高电平。空载 4.97 V，带两个 AUX 口、示波器、PFI3 后降到 4.3–4.5 V | 约 0 V：P0.6 没接到 USER 1 |
| CH2 G1 | 2.00 V | 设 2 Vpp → **TRIG IN 有 50 Ω** | 约 4 V：TRIG IN 没接上；约 1 V：幅度设错，太接近 ATS 门槛 0.87 V，会漏触发（§3.2） |
| CH3 G2 | 1.06 V | 设 1 Vpp → **CH A 有 50 Ω** | 约 2 V：CH A 还没被程序设成 50 Ω（跑一次 B 就好），或线没接 |

- **Top / Base**：脉冲「平台」和「底」的电平，示波器取最常出现的值，避开边沿上的尖。**Amp** = Top − Base。**Max / Min**：整屏最高、最低点，**包括尖**。
- **Over** = (Max − Top) / Amp，**Pre** = (Base − Min) / Amp。CH2：(3.12 − 2.00) / 2.00 = 56 %，(−0.003 + 1.08) / 2.00 = 54 %。来源是示波器那段分支线：末端 1 MΩ 不吸收，20 ns 的快边沿来回反射（屏幕上的「毛刺」）。TRIG IN 那一头更小（10/9 T2：37 %、峰值 2.72 V），远在 5 V 量程内。真正的检验是 **ctr1 = ATS 条数、nEdge 全是 1** → 没有多触发。

### 7.4 其他参数（知道是什么就行）
- **Vupper / Vmid / Vlower** = Base + 0.9 / 0.5 / 0.1 × Amp（CH1：0.079 + 0.9 × 4.40 = 4.04 V）。Rise 是从 Vlower 到 Vupper 的时间，+Wid 在 Vmid 处量。
- **Rise / Fall**：CH2、CH3 正好 20.00 ns = 5 个采样点，是被 4 ns 分辨率卡住的读数，真实边沿可能更快；CH1 40 ns（P0.6 带负载，边沿慢一些）。
- **+Rate / −Rate** = (Vupper − Vlower) / Rise，边沿斜率（CH2：1.60 V / 20 ns ≈ 80 MV/s）。
- **Avg / Vrms / Area**：在整屏 12 µs 上平均或积分，取决于脉冲占屏幕多长时间，对我们没意义（CH2 Area ≈ 2 V × 5 µs = 10 µVs）。
- **`*****`** = 量不出来：Freq/Period 要两个以上周期在屏幕里；CH1 Fall 的下降沿在屏幕外。
