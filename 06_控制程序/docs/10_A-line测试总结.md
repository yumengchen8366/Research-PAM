## 4 导师的要求 → 证据
| 导师问的 | 现在能回答 |
|---|---|
| 触发从哪来、触发条件 | 测试用：发生器 → TRIG IN（50 Ω），上升沿；真实系统：激光 → 光电二极管 → ATS（已实测成功）。LabVIEW 原来用 CH B 接光电二极管当触发源（见 02） |
| trigger level 的含义 | 0–255 的编码，128 = 0 V；±5 V 量程下 150 ≈ 0.87 V；实测阈值 0.8–0.9 V |
| trigger delay 怎么设、怎么验证 | 两种：信号到达的延时（发生器设，测得差值 1.9997 µs）；采集卡自己的延时（单位是采样点、必须是偶数，180 点 = 1 µs，实测窗口后移 1.0018 µs） |
| sample rate、采样长度 | 180 MS/s = 每点 5.56 ns；1024 点 = 5.689 µs；时间轴验证到 360 个点 |
| sample rate / trigger rate / trigger delay 的区别 | 采样率：一条记录里多久一个点（5.56 ns）；触发频率：多久采一条（100 kHz = 每 10 µs）；触发延时：触发后等多久开始记（0 或 1 µs）。三者互不影响 |
| filter | 约 20 MHz 低通；打开后边沿变慢、振铃消失、噪声不变 → 现在关；以后看换能器频率再定 |
| 两个通道、同步、固定延时 | 发生器 CH1 = 触发，CH2 = 信号；同频 + Align + Phase；示波器自动 Delay 核对 |
| 采到的时序和示波器一致 | 差值一致到约 10 ns；重复性 1–2 ns |
| 不能用软件循环采多条 | 一次 arm、硬件触发、DMA 收 buffer；100 kHz × 1000 条不漏；软件循环每条要几十毫秒，100 kHz 下会漏掉几千个 |

## 5 硬件上查清的事实（详见 01）
- ATS9462 TRIG IN 约 50 Ω；外触发量程 ±5 V 有效。
- 函数发生器 RIGOL DG852 Pro：切换 Imped 只改显示、不改输出；Pulse 波形不能 burst（用 Square + Idle Level = Bottom）。
- 示波器 RIGOL DS1054Z（50 MHz，输入只有 1 MΩ）。
- 激光 Thorlabs NPL45C：450 nm，Class 3B，只能外触发，输入 0.2–2 V、5 kΩ，最高 50 kHz。
- 光电二极管 Thorlabs PDA10A2。
- BNC-2110：P0.6、P0.7 的触发线目前是断开的（BNC 转接头只接了地线）。

## 6 LabVIEW 对照要点（详见 02、03）
- Main 默认：触发源 **Chan_B**（电平 144 ≈ 0.5 V），CH1 ±200 mV（光声），CH2 ±4 V（光电二极管），100 MS/s，Trig Delay 3.5 µs，Trig Rate 100 kHz，DO 500 kS/s，Motor Pulse Rate 16 kHz。
- 触发位 P0.6（DAQ）、P0.7（激光）由 GenerateSkipPulses 生成；SendCOPulses（计数器 → PFI0）Main 没用。"terminal 7"最可能是 P0.7，待和导师确认。

## 7 操作上学到的
- 每次运行 MATLAB 前，先在示波器上确认信号（幅度、底在 0 V、单位）。
- 发生器先设 Imped（接 50 Ω 用 Load，接高阻用 HighZ），再输入幅度；单位别选成 mVpp / µVdc。
- 量时间差用示波器的自动 Delay 测量（50% 处），不用光标；读统计前先清零。
- 示波器看 µs 级脉冲要用 µs 级时基；数 burst 用 Single。
- MATLAB 出现 `K>>` 是停在断点：`dbclear all` + `dbquit`。
- 每个文件都写 `cfg.note`，回家一看就知道是什么设定。
