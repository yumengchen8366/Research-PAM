# 05 参数字典

每个参数一行。目标是看到任何一个参数，都能说出它是什么、在哪里、改了会怎样、怎么验证。

> 10/4：按用户要求，由 Claude 根据 SDK 手册和 SDK 自带示例补齐了 A-line 和多条采集的参数（依据写在最后一列，来源见表后的"依据说明"）。每一行都要自己读一遍，能用自己的话讲出来。标"待做"的是还要在实验室验证的；标 ⚠ 的是手册和实测对不上、还要查清的。

| inputImpedanceId | `cfg.inputImpedanceId` → `AlazarInputControlEx` | Ω | 50 Ω | CH A 输入端对信号源呈现的负载 | 50 Ω：量程最大 ±4 V，线的末端被端接，快信号不反射；1 MΩ：量程最大 ±16 V，但不端接，快边沿会在线里反射 | 发生器 Imped = Load 时，ATS 读数应等于发生器显示值（1.3：200 mV → 203 mV ✔） | [板卡表]。真实系统要按放大器的输出要求来定（放大器型号待确认） |
| inputCouplingId | `cfg.inputCouplingId` → `AlazarInputControlEx` | — | DC | DC：直流和交流成分都进来；AC：用电容隔掉直流，基线会回到 0 附近 | AC 能去掉直流偏置，但很长的脉冲会"下垂"，低频成分也会变 | 用一个带直流偏置的信号，比较两种设置下的基线 | [板卡表] ATS9462 支持 AC 耦合 |
