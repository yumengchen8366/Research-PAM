PAM 扫描控制手册

用 MATLAB 通过 NI PCIe-6323 + BNC-2110 控制卓立汉光电动滑台、激光触发和 ATS9462 采集。本页汇总硬件配置、接线、已验证的结论、踩过的坑和当前代码，可以直接交给另一台电脑上的 Claude 继续工作。

handoff prompt
我在做光声显微（PAM）扫描系统的 MATLAB 控制，下面是之前和 Claude 一起确认过的背景，请在此基础上继续：

【硬件】实验室电脑：Windows 11、i5-14400F、64 GB、RTX 4060、MATLAB R2024b（含 Data Acquisition Toolbox + NI-DAQmx 支持包）、NI-DAQmx 24.5、LabVIEW 2024。
- NI PCIe-6323（设备名 Dev1）：32 AI（±0.2/1/5/10 V，16 位，总 250 kS/s）、4 AO（±10 V）、48 DIO、4 个 32 位计数器。
- BNC-2110 接在 6323 的 CONNECTOR 0（AI 0–15），可用：AI0–7（差分）、AO0/1、P0.0–P0.7、PFI 端子。
- AlazarTech ATS9462 数字化仪（2 通道、16 位、180 MS/s），外部触发 TRIG IN。
- 卓立汉光 CXPF50-80100 电动滑台：行程 50 mm，导程 2 mm，二相步进电机 SST43D2126-10（1.7 A/相，1.8°），最大 20 mm/s。
- 鸣志 SR2 步进驱动器：STEP/DIR 为共阳极低电平有效输入（COM+、STEP、DIR、EN），STEP 下降沿走一步，EN 悬空 = 使能。

【接线】BNC-2110 +5V → SR2 COM+；P0.0 → STEP；P0.1 → DIR；EN 不接。LabVIEW DO 位分配：Bit0 X STEP、Bit1 X DIR、Bit2 Y STEP、Bit3 Y DIR、Bit4 Z STEP、Bit5 Z DIR、Bit6 DAQ 触发（→ ATS TRIG IN，待确认）、Bit7 激光触发（待确认）。

【已验证】MATLAB 用硬件定时数字输出（N×列 的 0/1 矩阵，每列一条线、每行一个采样点）控制电机，滑台已能移动、换向。
- MATLAB daq 工具箱的定时数字输出必须在同一个 daq 对象里加一个模拟通道借时钟（我们加 ai1 输入，用 readwrite），否则报 "clock ... is not configured"；AI 时钟上限 250 kS/s。
- "Hardware is reserved"：先 clear 旧 daq 对象 + daqreset，并关闭 LabVIEW。
- 计数器 ctr0 固定输出到 PFI12（P2.4），Python 脚本用它触发 ATS；P0.0 不是 PFI，计数器到不了。
- 每脉冲距离 = 2000 µm / SR2 每转步数（20 细分时 0.5 µm）；SR2 细分需按拨码/实测校准。

【代码】test2.m：输入带正负号的 MOVE_UM 和速度移动滑台。bscan_test.m：加速-匀速-减速-返回，匀速段每 K 步同时发 DAQ 触发和激光触发，ATS9462 每触发采一条 A-line（ATS 部分尚未在硬件上测试）。

【下一步】确认 P0.6→ATS TRIG IN、P0.7→激光；校准 STEPS_PER_REV；先 LASER_ENABLE=false 跑 bscan_test 测通电机 + ATS，再开激光。
如果当前这台电脑没有连接这些硬件，请只做代码修改和分析，不要假设能运行硬件。

02信号是怎么走的

控制：MATLAB 数组 → NI-DAQmx 驱动 → PCIe → 6323（DO / DAC）→ 68 针电缆 → BNC-2110 端子
       → STEP/DIR → SR2 驱动器（放大成 1.7 A 相电流）→ 电机 → 滚珠丝杠 → 滑台
       → P0.7 → 激光外触发
       → P0.6 → ATS9462 TRIG IN → 采一条 A-line → DMA → MATLAB

读取：传感器电压 → BNC-2110 AI → 6323 多路开关 → 放大器 → 16 位 ADC → PCIe → 驱动 → MATLAB（单位 V）
  • BNC 线和端子里传的只有电压，含义由两端设备和换算系数决定。
  • NI-DAQmx 是驱动（C:\Windows\System32\nicaiu.dll + 内核驱动 + 后台服务）；PCIe 是主板上的硬件通道。
  • MATLAB 里画的"计划时序图"是由矩阵算出来的，不是实测。没接信号的 AI 通道读数是悬空乱值（例如 6.7 V 附近或缓慢漂移）。

04运动换算

200（整步）10 µm2 kHz
4000（20 细分，代码默认）0.5 µm40 kHz
8000（40 细分）0.25 µm80 kHz
  • 每脉冲距离 = 2000 µm ÷ 每转步数；距离 = 脉冲数 × 每脉冲距离；速度 = 步频 × 每脉冲距离。
  • bscantest.m 里 kx = 0.25，在 2 mm 导程上对应 40 细分，和代码默认的 20 细分不一致。以 SR2 拨码或实测为准，修改 STEPS_PER_REV。
  • B-scan：扫描速度 = A-line 间距 × 触发频率；A-line 间距必须是每脉冲距离的整数倍。

07代码

两份脚本默认都是检查模式（RUN_HARDWARE = false），只计算和画图。确认参数后再改成 true。

test2.m：按距离移动滑台

每次只改 MOVE_UM（µm，正负决定方向）和 SPEED_MM_S。

test2.m
%% 步进电机移动测试：Dev1 数字线输出 STEP/DIR → 鸣志 SR2 驱动器 → 卓立汉光 CXPF50-80100 电动滑台
%
%  原理：SR2 在 STEP 线的每个下降沿走一步（一个微步）；DIR 线高/低决定方向。
%        移动距离 = 脉冲数 × 每个脉冲的距离；速度 = 脉冲频率 × 每个脉冲的距离。
%        脉冲由采集卡按硬件时钟产生，个数和间隔是精确的。
%
%  CXPF50-80100：行程 50 mm，丝杠导程 2 mm，电机 200 整步/转 → 整步 10 um，最大速度 20 mm/s
%
%  使用前必须确认：
%   1. SR2 拨码开关的细分（每转步数），算出 UM_PER_PULSE
%   2. 滑台在行程中间，留有余量；已关闭占用 Dev1 的 LabVIEW 程序；激光处于安全状态

RUN_HARDWARE = false;              % false：只计算并画图；确认无误后再改成 true
COUNT_CHECK  = false;              % true：用 ctr1 实测发出的脉冲数，需先用导线把 P0.0 并接到 P1.3 (PFI3)

%% 1. 每次移动只改这两行
MOVE_UM    = -1000;                 % 移动距离 um：正数 = 一个方向，负数 = 反方向
SPEED_MM_S = 1;                    % 移动速度 mm/s（上限 20）

%% 2. 硬件参数（接线和驱动器设置不变时不用改）
STEP_LINE     = "port0/line0";     % P0.0 → SR2 STEP
DIR_LINE      = "port0/line1";     % P0.1 → SR2 DIR
POSITIVE_DIR  = 1;                 % MOVE_UM 为正时 DIR 输出的电平；方向反了就改成 0
STEPS_PER_REV = 200 * 20;          % SR2 细分设置：整步 200 x 细分数（请按拨码核对）
UM_PER_PULSE  = 2000 / STEPS_PER_REV;  % 导程 2000 um / 每转脉冲数；20 细分时 = 0.5 um
MAX_SPEED_MM_S = 20;               % CXPF 最大速度 20 mm/s
MAX_MOVE_UM    = 20000;            % 单次移动上限 20 mm（行程 50 mm），防止误输入撞到两端
CLOCK_AI       = "ai1";            % 给数字输出提供时钟的 AI 通道（只读，不输出）

%% 3. 由距离和速度换算出方向、脉冲数、脉冲频率
assert(abs(MOVE_UM) <= MAX_MOVE_UM, '单次移动 %.0f um 超过上限 %.0f um。', MOVE_UM, MAX_MOVE_UM);
assert(SPEED_MM_S > 0 && SPEED_MM_S <= MAX_SPEED_MM_S, '速度必须在 0 ~ %g mm/s 之间。', MAX_SPEED_MM_S);
if MOVE_UM >= 0
    DIRECTION = POSITIVE_DIR;
else
    DIRECTION = 1 - POSITIVE_DIR;
end
N_PULSES  = round(abs(MOVE_UM) / UM_PER_PULSE);
STEP_FREQ = SPEED_MM_S * 1000 / UM_PER_PULSE;   % Hz

fs = min(250e3, 20 * STEP_FREQ);   % 采样率：每个脉冲 20 行；AI 时钟上限 250 kS/s
DIR_SETUP = 100e-6;                % 先设好方向，再开始发脉冲
%% 4. 生成时序矩阵：列 1 = STEP，列 2 = DIR
period = round(fs / STEP_FREQ);              % 每个脉冲周期的行数
high   = max(1, round(period / 2));          % 50% 占空比
lead   = round(DIR_SETUP * fs);
N      = lead + N_PULSES * period + 1;       % 最后一行全部归零

do = false(N, 2);
k  = (0:N_PULSES * period - 1)';
do(lead + 1 : lead + N_PULSES * period, 1) = mod(k, period) < high;
do(1:end-1, 2) = logical(DIRECTION);

actual_freq = fs / period;
dist_um  = N_PULSES * UM_PER_PULSE;
speed_mm = actual_freq * UM_PER_PULSE / 1000;
fprintf('脉冲数 %d，实际频率 %.1f Hz，用时 %.3f s\n', ...
    nnz(diff([false; do(:,1)]) == 1), actual_freq, N / fs);
fprintf('方向 DIR = %d，预计移动 %+.1f um，速度 %.3f mm/s（上限 %g mm/s）\n', ...
    DIRECTION, sign(MOVE_UM) * dist_um, speed_mm, MAX_SPEED_MM_S);
assert(speed_mm <= MAX_SPEED_MM_S, '速度超过滑台上限，请降低 STEP_FREQ。');

% 这张图画的是上面算出来、准备发送的矩阵 do，不是从硬件测到的信号
figure('Name', 'Motor STEP/DIR (planned)', 'Color', 'w');
show = 1:min(N, lead + 5 * period);
stairs((show - 1) / fs * 1e3, double(do(show, 1)) * 0.8 + 0); hold on
stairs((show - 1) / fs * 1e3, double(do(show, 2)) * 0.8 + 1); hold off
yticks([0.4 1.4]); yticklabels(["STEP" "DIR"]); ylim([-0.2 2]);
xlabel('Time (ms)'); title('计划发送的前 5 个脉冲（计算值）'); grid on

%% 5. 输出到硬件
if ~RUN_HARDWARE
    fprintf('\n*** 检查模式：没有向硬件发送任何信号。要让电机动，把 RUN_HARDWARE 改成 true ***\n');
    return
end

% 释放 MATLAB 里之前创建、还占着 Dev1 的 daq 对象（例如命令行里建的 d、上次运行留下的 dq），
% 否则会报 "Hardware is reserved"。注意：LabVIEW 占用的资源这里释放不了，需要关闭 LabVIEW。
clear d dq cnt
daqreset

if COUNT_CHECK
    cnt = daq("ni");
    addinput(cnt, "Dev1", "ctr1", "EdgeCount");   % 计数输入在 PFI3 (P1.3)
    resetcounters(cnt);
    c0 = read(cnt, "OutputFormat", "Matrix");
end

% MATLAB 的 daq 工具箱规定：定时数字输出必须借用同一对象里模拟通道的采样时钟。
% 这里加一个 AI 通道当时钟（只读，不输出任何东西）。
% 如果把 P0.0 接到 BNC-2110 的 USER 1 端子，再用 BNC 线把 USER 1 接到 AI 1，
% 采回来的 meas 就是 STEP 线上的真实波形。
dq = daq("ni");
dq.Rate = fs;
ai = addinput(dq, "Dev1", CLOCK_AI, "Voltage");
ai.TerminalConfig = "Differential";
addoutput(dq, "Dev1", STEP_LINE, "Digital");
addoutput(dq, "Dev1", DIR_LINE,  "Digital");
meas = readwrite(dq, double(do), "OutputFormat", "Matrix");   % meas 只有接了 STEP 回环才有意义
fprintf('完成：已发送 %d 个脉冲，移动 %+.1f um\n', N_PULSES, sign(MOVE_UM) * dist_um);
clear dq    % 用完立即释放 Dev1，LabVIEW 或下一次运行才能使用

if COUNT_CHECK
    c1 = read(cnt, "OutputFormat", "Matrix");
    fprintf('ctr1 实测上升沿：%d（应为 %d）\n', c1 - c0, N_PULSES);
end

bscan_test.m：B-scan（滑台 + 激光触发 + ATS9462）

主要参数：SCAN_LENGTH_UM、DX_UM、TRIG_RATE_HZ。依赖 ATS-SDK 的 MATLAB Include 目录 C:\AlazarTech\ATS-SDK\23.3.0\Samples_MATLAB\Include。

bscan_test.m
%% B-scan：X 滑台匀速扫描 + 激光触发 + ATS9462 每个触发采一条 A-line
%
%  原理（全部由 Dev1 同一个硬件时钟产生，严格同步）：
%    P0.0 X STEP   ：加速 → 匀速 → 减速（→ 可选自动返回起点）
%    P0.1 X DIR    ：扫描方向，返回时翻转
%    P0.6 DAQ 触发 ：匀速段内每走 K 个脉冲（= DX_UM）发一次 → ATS9462 TRIG IN 采一条 A-line
%    P0.7 激光触发 ：与 DAQ 触发同一时刻（LASER_ENABLE = false 时不发）
%  因为触发是按"走了多少步"来发的，每条 A-line 的位置都正好间隔 DX_UM，不会出现 6.25 这类非整数关系。
%
%  先用 RUN_HARDWARE = false 检查时序和位置图；
%  再用 RUN_HARDWARE = true、LASER_ENABLE = false 测通 电机 + ATS 采集（采到的是无激光背景）；
%  最后确认激光安全后再 LASER_ENABLE = true。
%  运行前关闭 LabVIEW 和其他占用 Dev1 / ATS9462 的程序；滑台留出 扫描长度 + 2 x 加速距离 的余量。

RUN_HARDWARE    = false;   % false：只生成时序并画图，不碰任何硬件
LASER_ENABLE    = false;   % false：P0.7 不发激光触发
RETURN_TO_START = true;    % 扫描完自动以 RETURN_SPEED 退回起点
SAVE_DATA       = false;   % true：保存到 bscan_data 文件夹

%% 1. 扫描参数
SCAN_LENGTH_UM    = 2000;  % B-scan 长度
DX_UM             = 5;     % A-line 间距（必须是 UM_PER_PULSE 的整数倍）
TRIG_RATE_HZ      = 1000;  % 激光 / 采集触发频率 = 每秒 A-line 数；扫描速度 = DX_UM x TRIG_RATE_HZ
DIR_SCAN          = 1;     % 扫描时 DIR 电平（1 或 0）
RAMP_UM           = 200;   % 加速、减速各用多少距离（这段不采数据）
START_FREQ_HZ     = 500;   % 加速起始步频
RETURN_SPEED_MM_S = 2;     % 返回速度

%% 2. 硬件参数
STEP_LINE     = "port0/line0";
DIR_LINE      = "port0/line1";
DAQTRIG_LINE  = "port0/line6";      % → ATS9462 TRIG IN（请确认接线）
LASER_LINE    = "port0/line7";      % → 激光外触发输入（请确认接线和激光的触发要求）
STEPS_PER_REV = 200 * 20;           % SR2 细分设置（以 test2.m 实测校准过的值为准）
UM_PER_PULSE  = 2000 / STEPS_PER_REV;
MAX_SPEED_MM_S = 20;
MAX_TRAVEL_UM  = 20000;             % 单次扫描总行程上限（滑台行程 50 mm）
TRIG_WIDTH_S   = 10e-6;             % 触发脉宽
CLOCK_AI       = "ai1";             % 给数字输出提供时钟的 AI 通道（只读）
FS_MAX         = 250e3;             % AI 时钟上限
DIR_SETUP_S    = 100e-6;
PAUSE_S        = 0.05;              % 扫描结束到返回之间的停顿

% ATS9462（与 ats9462_aline_test_revised.m 一致）
ATS.samplesPerALine   = 512;        % 每条 A-line 的点数（32 的倍数，>= 256）
ATS.sampleRate_Hz     = 180e6;
ATS.inputRange_V      = 4;          % 0.2 / 0.4 / 0.8 / 2 / 4
ATS.triggerLevelCode  = 150;        % ETR_5V 下约 0.87 V
ATS.triggerDelay      = 0;          % ADC 采样点，2 的倍数
ATS.recordsPerBuffer  = 50;         % 每个 DMA buffer 的 A-line 数
ATS.sdkInclude        = 'C:\AlazarTech\ATS-SDK\23.3.0\Samples_MATLAB\Include';

%% 3. 换算与检查
K = DX_UM / UM_PER_PULSE;                       % 每条 A-line 之间的脉冲数
assert(abs(K - round(K)) < 1e-9 && K >= 1, 'DX_UM 必须是 %.3f um 的整数倍。', UM_PER_PULSE);
K = round(K);
stepFreq = K * TRIG_RATE_HZ;
scanSpeed = stepFreq * UM_PER_PULSE / 1000;     % mm/s
assert(scanSpeed <= MAX_SPEED_MM_S, '扫描速度 %.2f mm/s 超过上限，请降低 TRIG_RATE_HZ 或 DX_UM。', scanSpeed);
assert(RETURN_SPEED_MM_S <= MAX_SPEED_MM_S, '返回速度超过上限。');

Nx = round(SCAN_LENGTH_UM / DX_UM);
Nx = ceil(Nx / ATS.recordsPerBuffer) * ATS.recordsPerBuffer;   % 凑成 buffer 的整数倍
nRamp = round(RAMP_UM / UM_PER_PULSE);
nScan = Nx * K;
travel = (2 * nRamp + nScan) * UM_PER_PULSE;
assert(travel <= MAX_TRAVEL_UM, '总行程 %.0f um 超过上限 %.0f um。', travel, MAX_TRAVEL_UM);

pScan = floor(FS_MAX / stepFreq);               % 每个脉冲的行数（整数，保证触发间隔精确）
assert(pScan >= 2, '步频太高，DO 时钟不够。');
fs = stepFreq * pScan;
wTrig = max(1, round(TRIG_WIDTH_S * fs));
assert(wTrig < K * pScan, '触发脉宽太长。');

%% 4. 生成时序：列 1 STEP，列 2 DIR，列 3 DAQ 触发，列 4 激光触发
up      = rampPeriods(nRamp, START_FREQ_HZ, stepFreq, fs, pScan);
segScan = [up; repmat(pScan, nScan, 1); flipud(up)];
trigOn  = [false(nRamp, 1); mod((0:nScan-1)', K) == 0; false(nRamp, 1)];
stepScan = stepColumn(segScan);
startsScan = [0; cumsum(segScan(1:end-1))];
trigScan = false(size(stepScan));
idx = startsScan(trigOn) + (1:wTrig);
trigScan(idx(:)) = true;

if RETURN_TO_START
    fRet = RETURN_SPEED_MM_S * 1000 / UM_PER_PULSE;
    pRet = max(2, round(fs / fRet));
    upR  = rampPeriods(nRamp, START_FREQ_HZ, fRet, fs, pRet);
    segRet = [upR; repmat(pRet, nScan, 1); flipud(upR)];   % 与去程步数相同
    stepRet = stepColumn(segRet);
else
    stepRet = false(0, 1);
end

lead  = round(DIR_SETUP_S * fs);
pause_rows = round(PAUSE_S * fs);
nA = numel(stepScan); nR = numel(stepRet);
N  = lead + nA + pause_rows + nR + 1;           % 最后一行全部归零
do = false(N, 4);
rA = lead + (1:nA);
do(rA, 1) = stepScan;
do(rA, 3) = trigScan;
if LASER_ENABLE
    do(rA, 4) = trigScan;
end
dirSwitch = lead + nA + floor(pause_rows / 2);  % 停顿中途翻转 DIR
do(1:dirSwitch, 2) = logical(DIR_SCAN);
if RETURN_TO_START
    rR = lead + nA + pause_rows + (1:nR);
    do(rR, 1) = stepRet;
    do(dirSwitch+1 : N-1, 2) = ~logical(DIR_SCAN);
end

%% 5. 检查：位置和触发位置（由 do 矩阵推算，不是实测）
fall = [false; diff(do(:,1)) == -1];            % SR2 在 STEP 下降沿走一步
sgn  = 2 * (do(:,2) == logical(DIR_SCAN)) - 1;
pos_um = cumsum(fall .* sgn) * UM_PER_PULSE;
tr = find(diff([false; do(:,3)]) == 1);
xA = pos_um(tr);
spacing = diff(xA);
t = (0:N-1)' / fs;

fprintf('A-line 数 %d，间距 %.2f um（实际 %.2f ~ %.2f um），B-scan 长度 %.2f mm\n', ...
    numel(tr), DX_UM, min(spacing), max(spacing), (xA(end) - xA(1)) / 1000);
fprintf('扫描速度 %.2f mm/s，步频 %.0f Hz，触发 %.0f Hz，DO 采样率 %.0f S/s\n', ...
    scanSpeed, stepFreq, TRIG_RATE_HZ, fs);
fprintf('总行程 %.2f mm，总用时 %.2f s，结束位置 %+.1f um，激光触发：%s\n', ...
    travel / 1000, N / fs, pos_um(end), string(LASER_ENABLE));

figure('Name', 'B-scan plan (computed)', 'Color', 'w');
subplot(2,1,1);
plot(t, pos_um / 1000); hold on
plot(t(tr), xA / 1000, 'r.', 'MarkerSize', 4); hold off
xlabel('Time (s)'); ylabel('X (mm)'); grid on
title(sprintf('计划位置（计算值），红点 = %d 个触发位置', numel(tr)));
subplot(2,1,2);
z = tr(1) - 2*K*pScan : tr(3) + K*pScan;
z = z(z >= 1 & z <= N);
labels = ["X STEP" "X DIR" "DAQ Trig" "Laser Trig"];
hold on
for c = 1:4
    stairs(t(z) * 1e3, double(do(z, c)) * 0.8 + (c - 1));
end
hold off
yticks((0:3) + 0.4); yticklabels(labels); ylim([-0.2 4]);
xlabel('Time (ms)'); title('第一个触发附近的时序（计算值）'); grid on

%% 6. 运行硬件
if ~RUN_HARDWARE
    fprintf('\n*** 检查模式：没有向硬件发送任何信号。确认无误后把 RUN_HARDWARE 改成 true ***\n');
    return

%% ===== 本地函数 =====
function p = rampPeriods(n, f0, f1, fs, pMin)
% 线性加速：步频从 f0 增加到 f1，返回每一步的行数
    if n == 0
        p = zeros(0, 1);
        return
    end
    f = linspace(min(f0, f1), f1, n)';
    p = max(pMin, round(fs ./ f));
end

function col = stepColumn(periods)
% 每一步：前一半行为高，后一半为低
    starts = [0; cumsum(periods(1:end-1))];
    col = false(sum(periods), 1);
    for i = 1:numel(periods)
        col(starts(i) + (1:max(1, floor(periods(i) / 2)))) = true;
    end
end

function raw = runBscan(do, fs, doLines, clockAI, Nx, P)
% 先把 ATS9462 准备好（所有 DMA buffer 预先提交），再让 Dev1 输出整个时序。
    addpath(P.sdkInclude);
    AlazarDefs;
    alazarLoadLibrary();
    board = AlazarGetBoardBySystemID(int32(1), int32(1));
    [~, bits] = AlazarGetChannelInfo(board);
    assert(double(bits) == 16, 'Expected 16-bit ATS9462.');

    rateIds  = containers.Map({100e6, 160e6, 180e6}, ...
        {SAMPLE_RATE_100MSPS, SAMPLE_RATE_160MSPS, SAMPLE_RATE_180MSPS});
    rangeIds = containers.Map({0.2, 0.4, 0.8, 2, 4}, ...
        {INPUT_RANGE_PM_200_MV, INPUT_RANGE_PM_400_MV, INPUT_RANGE_PM_800_MV, ...
         INPUT_RANGE_PM_2_V, INPUT_RANGE_PM_4_V});
    AlazarSetCaptureClock(board, INTERNAL_CLOCK, rateIds(P.sampleRate_Hz), CLOCK_EDGE_RISING, 0);
    AlazarInputControlEx(board, CHANNEL_A, DC_COUPLING, rangeIds(P.inputRange_V), IMPEDANCE_50_OHM);
    AlazarSetBWLimit(board, CHANNEL_A, 0);
    AlazarSetExternalTrigger(board, DC_COUPLING, ETR_5V);
    AlazarSetTriggerOperation(board, TRIG_ENGINE_OP_J, TRIG_ENGINE_J, TRIG_EXTERNAL, ...
        TRIGGER_SLOPE_POSITIVE, P.triggerLevelCode, TRIG_ENGINE_K, TRIG_DISABLE, ...
        TRIGGER_SLOPE_POSITIVE, 128);
    AlazarSetTriggerDelay(board, P.triggerDelay);
    AlazarSetTriggerTimeOut(board, 0);
    AlazarConfigureAuxIO(board, AUX_OUT_TRIGGER, 0);

    spr = P.samplesPerALine;
    rpb = P.recordsPerBuffer;
    nBuf = Nx / rpb;
    bytesPerBuffer = 2 * spr * rpb;
    buffers = cell(1, nBuf);
    for i = 1:nBuf
        buffers{i} = AlazarAllocBuffer(board, bytesPerBuffer);
    end
    guard = onCleanup(@() releaseAll(board, buffers)); %#ok<NASGU>

    AlazarSetRecordSize(board, 0, spr);
    AlazarBeforeAsyncRead(board, CHANNEL_A, 0, spr, rpb, Nx, ...
        bitor(ADMA_EXTERNAL_STARTCAPTURE, ADMA_NPT));
    for i = 1:nBuf
        AlazarPostAsyncBuffer(board, buffers{i}, bytesPerBuffer);
    end
    AlazarStartCapture(board);
    fprintf('ATS armed：等待 %d 个触发...\n', Nx);

    dq = daq("ni");
    dq.Rate = fs;
    ai = addinput(dq, "Dev1", clockAI, "Voltage");
    ai.TerminalConfig = "Differential";
    for k = 1:numel(doLines)
        addoutput(dq, "Dev1", doLines(k), "Digital");
    end
    readwrite(dq, double(do), "OutputFormat", "Matrix");
    clear dq
    fprintf('Dev1 时序输出完成。\n');

    raw = zeros(spr, Nx, 'uint16');
    for i = 1:nBuf
        ret = AlazarWaitAsyncBufferComplete(board, buffers{i}, 2000);
        if ret ~= ApiSuccess
            error('Bscan:Buffer', 'Buffer %d/%d 未完成（返回码 %d）：检查 P0.6 是否接到 ATS TRIG IN。', ...
                i, nBuf, ret);
        end
        setdatatype(buffers{i}, 'uint16Ptr', 1, spr * rpb);
        raw(:, (i-1)*rpb + (1:rpb)) = reshape(buffers{i}.Value, spr, rpb);
    end
end

function releaseAll(board, buffers)
    try
        AlazarAbortAsyncRead(board);
    catch e
        warning('Bscan:Abort', 'DMA abort failed; buffers NOT freed. Restart MATLAB. %s', e.message);
        return
    end
    for i = 1:numel(buffers)
        try
            AlazarFreeBuffer(board, buffers{i});
        catch
        end
    end
end
