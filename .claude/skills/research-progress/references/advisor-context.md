# 当前 PAM 导师的指导偏好与阶段要求

- 依据用户在 2026-09-28 新上传并要求更新的《UV-PAM 导师会谈整理（定稿）.md》，替代此前同日的英文文件名版本。正文归档见 `pam-meeting-final-2026-09-28.md`；该日期是整理和更新日期，实际会谈日期未独立确认。
- 保留此前 2026-09-23 背景摘要中关于现有系统、时序和逐步独立工作的脉络。不得把不同时期的目标合并成本次新要求。
- 最终附件是语义整理稿，含明确要求、分析、技术补充和建议。用户认可其作为最终版本，不等于其中所有内容都成为教授原话。
- 沿用新稿的【明确】【解读】【待确认】标记。第八节是技术补充，第九节是整理者建议；不能将这两节自动升级为教授新增要求。技术解释另核对 `pam-technical-checks.md`。
- 只用于当前 CWRU PAM 导师；其他导师使用通用研究流程。新明确反馈、最新文件和实测结果优先。
- 将“性格”落实为有谈话依据的指导偏好，不建立严厉、没耐心、不喜欢基础问题等人格结论，不预测导师一定会怎样反应。

## 由谈话支持的指导偏好

| 表达或追问 | 可持续采用的帮助方式 |
|---|---|
| PAM 是什么、测什么，样品 A/B 信号差异说明什么？ | 讲清基本过程、直接检测量、成像信息及判断条件；把泛泛的“不同信息”具体到物理量 |
| 电压、频率代表什么，谁说必须做 Fourier transform？ | 先定义对象和分析目的，检查问题前提，再选择工具 |
| 为什么问大家用超声换能器？你的思考过程是什么？ | 区分不知道原理、缺本机信息、比较替代方案；准确定位连接处 |
| 带宽属于谁，0.4 与 150 含义是什么？ | 核对器件、配置函数、单位或编码以及硬件作用范围 |
| 需要多少采样率，更高或更低会怎样？ | 区分能力上限和实际需求，解释选择依据和取舍 |
| NA 中角度在哪里、由什么决定、怎样改变？ | 从公式进入几何和因果关系，再对应当前光路 |
| 上次公式、扩束的问题后来理解了吗？ | 跟进旧问题，说明新解释、新依据和未解决部分 |
| 从头逐项讲会变成 lecture，但查过仍不懂可以讨论 | 帮用户准备初步解释和具体卡点；允许求助，也可以请求具体操作演示 |
| 可以按自己的 pace，未要求达到某位同学水平 | 根据实际基础安排进度，不以同学比较或个人估时设硬性标准 |

他强调主动了解项目基础，并建议结合教材、原论文、手册、示例代码和组员交流，也建议用 AI 帮助解释具体资料。助手应实际协助阅读和推理；不能将主动性误解为拒绝回答基础问题。

## 当前阶段、后续能力与证据

- 本次主要要求：能够解释 PAM 基础，把概念对应到器件和程序，说明参数选择的依据，并推进之前的问题。
- 新稿将理解程度概括为“定义、位置、因果、依据”四层。这是可采用的检查方法，不是教授逐字指定的评分标准。他明确说现阶段不要求解释每个频率成分。
- 通过采样率和 NA 的追问，可以确认他在检查对条件变化的解释能力。
- 具体实验验证、任务卡、参数表、一页信号说明和学习检查题，是整理者提出的方法，不能自动写成教授布置的作业。
- 此前的 motor、激光和采集时序理解，以及逐步按需求修改扫描、独立搭建系统，属于更广的研究发展脉络；并非本次立即完成的新增任务。
- 看资料能跟上、能独立解释、能对应本机、能预测、已有验证证据，是不同状态。帮助用户指出当前达到哪一步，不能把读过资料写成验证成功。
- 具体事务包括幻灯片写姓名和日期、查换能器教材、先读当时 ATS9462 spec 的前三四页和示例代码、围绕原资料使用 AI、继续与已有可运行程序的同学讨论。前三四页是起点；解决具体参数仍应查对应规格表和 API。
- “先弄透再往下”落实为先补当前问题的关键前提，不能扩展成必须一次掌握全部光学、暂停编程或永远不能带未解问题求助。

## 历史实例；每次使用前核对最新状态

- 最终稿记录：用户重新看 A/B-scan 程序、开始写 A-line 代码、看教学视频，也已向组员询问采样率。这些是当时报告，不能抹去已有努力，也不能自动视为今天刚完成的工作。
- 当时尚未报告可靠目标光声信号；水耦合和 alignment 被讨论，但原因未确认。后续可能已经取得信号，应以新记录为准。
- JoVE、ATS9462、NPT 与 Triggered Streaming 是转录或上下文中的名称线索，具体版本、模式和配置仍需原始资料确认。最终稿有些段落直接使用名称，执行时仍保留这层限制。
- 0.4、150、65/20 MHz、180/160/80 及 500/1G 用来讨论参数含义和选择依据；不据此设置硬件。此前的 16 kHz、100 kHz 等同样不能仅凭数值判定信号归属。
- 本次没有确定最终带宽、量程、触发电压、采样率或无信号原因，也没有给出学完全部基础的硬性日期。
- 十分钟、二三十分钟、半小时到一小时是教授对部分问题的估时，不是统一验收标准。某次十点结束及历史周一/周五 meeting 不是当前固定安排。
- “不必汇报已经懂的内容”等含糊表述不能升级为限制。可以优先讨论疑点，同时简要展示新理解。
- 不能将 “wrong start” 等不清楚片段解释成禁止写代码，也不能因一位组员先求可运行就贬低其工作或用户能力。

## 使用 26 项问题索引

仅在回顾或查漏时查看最终稿第四部分。新稿合并重复问法后共 26 项，分为 PAM 原理、提问与学习方式、实验、采集卡参数、光路五组。第六节整理目标程度，第七节保留未决事项，第八节提供技术补充，第九节提供行动与跟进模板。按当前任务选择少量相关项，不把整张清单变成当天作业。

## 何时帮助用户求助

有具体疑点、资料与行为冲突、重复尝试已无新信息或本机操作缺少训练时，就帮助整理问题并请求判断或演示。请求前如实呈现已知、尝试及证据；不要求先成功，不把“独立研究”理解为永远不求助。
