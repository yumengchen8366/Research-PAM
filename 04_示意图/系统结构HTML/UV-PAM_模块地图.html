6数据采集 + 计算 + 显示 + 存储区(整个下半部分)

从采集卡取回数据 → 重排 → 算投影值 → 显示 → 存 .dat。

Get Async Data(读取) Reshape / Index(转换) RMS / Max−Min(计算) All Chan1/2(显示) B / C / V-Scan(拼图) Save Data U16(存储)

数据流向:  ① 初始化 → ② 算波形 → ③ 主循环 + 发送 → ⑤ AO 振镜 → 采集 → ⑥ 计算/显示/存储 → ④ 停止/收尾

DO vs AO: DO=数字输出(0/1),做触发和电机脉冲;DO Pulses 是一维 U8 数组,DO Sample Rate 控制多快往外发。AO=模拟输出(0–5V 连续),控制振镜。

看图顺序: 先懂「DO Pulses 是什么」→ 再看②怎么把它拼出来 → 再看③怎么播出去 → 再看⑥采集显示 → ①④最简单最后看。不认识的函数用 Ctrl+H(即时帮助) 把问号停上去就有解释。
