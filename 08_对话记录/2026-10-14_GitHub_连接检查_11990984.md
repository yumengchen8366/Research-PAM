### 🤖 Claude · 2026-10-14 03:32

可以，而且你现在的 `bscan_test.m` 本来就是从它来的。但要分清「拿它的什么」。

**先对一下两份代码**

SDK 示例 `ATS9462_NPT.m`（`07_MATLAB/_Mac下载版本/`，你还有一份加注版）的调用顺序是：SetCaptureClock → InputControlEx → SetExternalTrigger → SetTriggerOperation → SetRecordSize → BeforeAsyncRead → AllocBuffer / PostAsyncBuffer → StartCapture → **while 循环：Wait → 处理 → 重新 Post** → AbortAsyncRead → FreeBuffer。

`bscan_test.m:245–310` 的 `runBscan` 走的是同一条线，区别只有一处：你把 `Nx/rpb` 个 buffer 一次全 Post 了，所以省掉了示例第 307–393 行的「重新 Post」循环。这正是 docs/12 §三点五 说 C-scan 要补回去的东西。

**C-scan 能从示例里直接搬的**
- 示例第 307–393 行的循环骨架：`AlazarWaitAsyncBufferComplete` → `setdatatype` 拷出 → `AlazarPostAsyncBuffer` 交回 → `buffersCompleted` 计数 → 到数就退出。这是「buffer 轮换」的标准写法，docs/14 阶段 6.11 的行内 ring buffer 就用它。
- 示例第 355–357 行的 `fwrite(fid, pbuffer.Value, 'uint16')`：逐 buffer 追加写二进制文件，比 docs/14 1.4 的 `matfile` 更简单、更快。两种都行，先定一种。
- 示例第 192–198 行的注释：trigger rate ÷ recordsPerBuffer 要小于 2 kHz。docs/14 附 A 的「400 ÷ 2 = 200 < 2 kHz」就是这条。
- 示例第 402–415 行的收尾顺序：先 Abort、再 Free。你的 `releaseAll` 已经是这样。

**示例没覆盖、必须自己写的**
1. **NI 时序和 ATS 不能同时阻塞**。示例的 Wait 是阻塞的，你的 `readwrite`（`bscan_test.m:296`）也是阻塞的，同一个线程跑不了两个 while。docs/14 的解法是**每行单独 arm**：Post 本行 5 个 buffer → `readwrite` 行表 → 依次 Wait 5 个。这期间数据靠板载内存接住。第一版 10×10 每行只要 5 个 buffer，所以其实**不需要示例的 while 循环**，就是把 `runBscan` 的结构重复 Ny 次。
2. **哪些放循环外**：板卡配置（`bscan_test.m:252–266`）、AllocBuffer、dq 对象、计数器，都只做一次。每行要重做的是 `AlazarBeforeAsyncRead`（`recordsPerAcquisition = Nx`）、Post、StartCapture、Wait。
3. **每行结束要 `AlazarAbortAsyncRead`，但不要 FreeBuffer**，下一行把同一批 buffer 再 Post 回去。示例里 Abort 只在最后做一次。「同一批 buffer 在 Abort 后重新 BeforeAsyncRead + Post」是 SDK 的常规用法，但本机没实测过，标 [待确认]，阶段 3 单行回归时第一个查。
4. 4096 字节对齐：rpb = 2、spr = 1024 → 每个 buffer 正好 4096 B，示例第 249 行的 `AlazarAllocBuffer` 没问题。

**不要照搬的**
- 示例的 TODO 默认值：`postTriggerSamples = 2048`、`recordsPerBuffer = 10`、`bufferCount = 4`、触发源设置。这些你在 B 里都已经按实测定了。
- 第 380 行的 `waitbar`：每个 buffer 刷一次 GUI，会拖慢循环，换成每行一句 `fprintf`。
- `buffersPerAcquisition == 7FFFFFFF` 那段无限采集的逻辑，用不到。

**建议的做法**：以 `bscan_test.m` 为底本写 `cscan_test.m`，因为 NI 时序表、assert、`onCleanup` 都已经验证过 400/400。示例只在两个地方当参考：行内 ring buffer 的循环形状，和收尾顺序。写的时候按 docs/14 阶段 1 先做离线检查模式，Mac 上就能跑。
